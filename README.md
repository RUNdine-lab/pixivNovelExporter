# pixiv小説原稿エクスポート / pixivNovelExporter (Chrome拡張機能)

## 概要と特徴
**ユーザー自身がpixivに投稿している小説をテキストファイル形式にし、まとめてzipでダウンロードするChrome拡張機能**です。  
web再録本の作成や個人サイトへの移行、ローカルバックアップなどの用途にお使いいただけます。  

- ダッシュボードの小説タブでボタンを押すだけの簡単動作
- 本文中のルビ・傍点等の記法をそのまま保持
- 外部サーバーへのデータ送信なし(自分のブラウザだけで完結)
- アカウント情報やログイン情報の取得なし
- OAuthなし

※投稿タイトル→ファイル名、投稿本文→ファイルの中身 になります。  
※紹介文、閲覧数、タグ、いいね、コメント等の付帯情報は保存しません。

## できること
### 「自分の作品 > 小説 > 作品」からの保存
ページに表示されている作品をすべて保存します。  
「絞り込む」を使って公開範囲・年齢制限・タグで絞り込んでいる場合には絞り込み結果を対象にして保存します。  
※数件だけ保存したい場合には一時的にタグをつけ、それで絞り込むのをおすすめします。

### 「自分の作品 > 小説 > シリーズ」からの保存
ページに表示されているシリーズをすべて保存します(収録作品はシリーズ別にフォルダ分けされます)。  
※pixivのシリーズAPIの取得件数に合わせ、現在は1シリーズあたり30話まで取得します。

## 対応ブラウザ
Chrome/Vivaldi等のChromium系ブラウザで動作確認。

## インストール
1. 本拡張機能をダウンロードします。
2. アドレスバーに chrome://extensions/ を入力して管理画面に移動し、右上の「デベロッパーモード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」(または「非パッケージ拡張機能を読み込む」)を通じて本拡張機能を登録します。

## 使い方
1. 自身のアカウントでpixivにログインし、
[「自分の作品 > 小説 > 作品」](https://www.pixiv.net/dashboard/works/novels)、
[「自分の作品 > 小説 > シリーズ」](https://www.pixiv.net/dashboard/works/novels/series)のどちらかを開きます。  
※**「小説」区分のみで動作**します。「すべて」「イラスト」を選択した状態では動作しませんのでご注意ください。
2. (任意) 「絞り込む」を押して必要な作品だけを表示します。
3. アドレスバー横に出ている本拡張機能のアイコンを左クリックし、「保存」を選択。

## 注意事項
- 本拡張機能は「自身がpixivへ投稿した小説をバックアップ・再録する」用途を想定しています(他者の著作物を取得する目的では設計していません)。
- 2026年8月現在のpixivの画面構成を前提とした仕組みになっています。pixiv公式の仕様変更により予期せず動作しなくなる場合があります。
- ブラウザ設定によっては複数ダウンロードの警告が出る場合があります。  
保存は実行できるにも関わらずファイルが保存されない場合は、アドレスバー右側の通知を確認してpixivからの複数ダウンロードを許可してください。
- アクセス負荷軽減のため、短時間に繰り返し実行したり、大量の作品を連続取得したりする行為は避けてください。
